## 要点

### 1. 文体

- 本文は敬体か常体のどちらかに統一し、混ぜない。マニュアルのような一般の読者向けの本文では敬体を使う（出典: JTF §1.1.1 p.10）
- 一つの文書の中で常体と敬体を混ぜない。ただし、引用・従属節・箇条書きで文末が変わるのは問題ない（出典: 公用文 解説 Ⅲ-1イ p.30）
- 常体で書くときは「である・であろう・であった」を使い、「だ・だろう・だった」は使わない（出典: 公用文 本体 Ⅲ-1ウ (7)、解説 p.30）
- 見出しは常体か体言止めにする。見出しの文末に句点は付けず、見出し全体で文体をそろえる（出典: JTF §1.1.2 p.10）
- 箇条書きは本文の文体に合わせる。本文が敬体なら、箇条書きを常体や体言止めにしてもよい。本文が常体なら、箇条書きに敬体は使わない。一つのまとまりの中では、文体と文末の句点の有無をそろえる（出典: JTF §1.1.3 p.11）
- 図表の中の文字とキャプションには、句点を付けない。複数の文になるときだけ句点を使う（出典: JTF §1.1.4–1.1.5 p.11）
- 解説・広報では文末を「です・ます」にし、「ございます」は使わない。「おります」「いたします」は多用しない（出典: 公用文 本体 Ⅱ-6ウ (6)）
- 文語の名残は口語に直す（「〜のごとく」→「〜のように」）。「べく」「べし」は使わない（出典: 公用文 本体 Ⅲ-1エ・オ (7)）

### 2. 表記

- 漢字は常用漢字表の字と音訓を優先する（「美味しい」→「おいしい」、「概ね」→「おおむね」）（出典: JTF 12の基本ルール 3、§2.1.2 p.2, p.13）
- 形式名詞は仮名で書く。事→こと、時→とき、所→ところ、物・者→もの、通り→とおり、様→よう、為→ため。具体的に特定できる対象があるときは漢字で書く（出典: 公用文 解説 Ⅰ-1(3)ア p.11）
- 例示の「等」は仮名で書く。「等」は「とう」と読ませるときだけ使う（出典: 公用文 解説 Ⅰ-1(3)ア p.11）
- 補助動詞は仮名で書く（〜ていく・〜てください・〜てみる・〜てほしい）。実際の動作を表すときは漢字で書く（出典: 公用文 解説 p.11、JTF §2.2.1 p.22–25）
- 「できる」「ある」「ない」は仮名で書く。接続詞の「さらに」「したがって」「また」も仮名だが、副詞の「更に」、動詞の「従う」、副詞の「又」は漢字で書く（出典: 公用文 解説 Ⅰ-1(3)イ・ウ p.11–12）
- 送り仮名は「送り仮名の付け方」の本則と例外に従う。複合動詞の送り仮名は省かない（取り扱う・申し込む）（出典: JTF §2.1.3–2.1.4 p.13–16）
- カタカナは全角で書き、半角カナは使わない（出典: JTF §2.1.5 p.17）
- 語末の長音は省かないのが原則（コンピューター・ユーザー・メモリー）（出典: JTF §2.1.6 p.17–18、公用文 解説 Ⅰ-3エ p.14）。ただし JTF は、業界によって表記がゆれていることを認めており（例: 記憶装置は「メモリ」）、同じ文書の中で統一することを重視している
- 外来語は「外来語の表記」の第1表を使う（ウイルス・デジタル）。第2表の表記（ウェブ・ウィルス）を使うときは、文書の中でそろえる（出典: 公用文 解説 Ⅰ-3 p.14）
- カタカナ複合語は、中黒・半角スペース・区切らない、のどれかに統一する（出典: JTF 12の基本ルール 6、§2.1.7 p.19–20）

### 3. 数字

- 横書きでは算用数字を使う（出典: 公用文 本体 Ⅰ-4ア (3)）。JTF は半角が原則（出典: JTF §2.1.8 p.20）。公用文は全角・半角を決めておらず統一だけを求めるが、データや金額は半角で書く（全角の数字は機械処理で数値として扱われないことがあるため）（出典: 公用文 解説 Ⅰ-4エ p.15）
- 桁区切りは3桁ごとの半角コンマ、小数点は半角ピリオド。「万・億」と組み合わせるときはコンマを省いてもよい（「3万8000人」）（出典: JTF §2.1.10 p.21、公用文 解説 Ⅰ-4イ・ウ p.15）
- 概数（数十人）、熟語・慣用表現（一時的・第三者）は漢数字を使う（出典: JTF §2.2.2 p.27–28、公用文 解説 Ⅰ-4オ・カ p.15）
- 「〜か所」「〜か月」と書き、「ヶ」は使わない。JTF は「カ」も認めている（出典: JTF §2.2.3 p.28、公用文 本体 Ⅰ-4ケ (3)）
- 単位記号の大文字・小文字は SI に従う。英字（kg）とカタカナ（キログラム）のどちらを使うかは決めて統一する（出典: JTF §4.1–4.2 p.36）

### 4. 記号・スペース

- 句読点は全角の「、」「。」を使う（出典: JTF §1.2.1 p.12）。公用文は横書きなら「，」も認めるが、文書の中でどちらかに統一する（出典: 公用文 本体 Ⅰ-5(1)ア (4)）
- 全角文字と半角文字の間にスペースを入れない。括弧の内側と外側にも入れない（出典: JTF §2.3.1, §2.3.3 p.28–29）
- 括弧の使い分け（出典: JTF §3.3 p.33–34）: 「」は引用・参照先・入力する文字、『』は書名と入れ子、［］は画面の用語、（）は補足・言い換え
- 中黒を、カタカナ複合語の区切りと語句の並列の両方に使わない（出典: JTF §3.2.4 p.32）
- 数値の範囲は全角の「～」で示す（18～22歳）（出典: JTF §3.2.5 p.32）
- 「！」「？」は本文で多用しない（出典: JTF §3.2.1–3.2.2 p.31–32）

### 5. 文の長さ・分かりやすさ

- 一文を短くし、一文の論点は一つにする。三つ以上を並べるときは箇条書きにする（出典: 公用文 本体 Ⅲ-3ア〜ウ (8)）
- **長さの目安は、50〜60字を超えたら読みにくくなっていないか見直すこと。** 解説自身が「一概に決められない」と断ったうえでの目安で、建議の本体ではなく解説にある（出典: 公用文 解説 Ⅲ-3ア p.32）
- 主語と述語の関係が分かるようにする。接続助詞や中止法を多用しない。同じ助詞を続けない。係る語と受ける語は近くに置く。受身形と二重否定を多用しない（出典: 公用文 本体 Ⅲ-3エ〜ス (8)）
- 結論を先に示し、理由や詳細はその後に書く（出典: 公用文 本体 Ⅲ-4イ (8)）
- 冗長な言い方を削る（「利用することができる」→「利用できる」、「調査を実施した」→「調査した」）。程度や期間は具体的に書く（「幾つか」→「3点」、「早めに」→「5月14日正午まで」）（出典: 公用文 本体 Ⅱ-5イ・ウ (6)）
- 例示の語（`など`・`等`）を使うときは、その前に代表的なものを挙げる（出典: 公用文 本体 Ⅱ-5イ(ウ) (6)）
- 見出しを追えば内容の全体がつかめるようにする（出典: 公用文 本体 Ⅲ-2 (7)）

### 6. 用語の統一・専門用語

- 用例集や用語集を作り、表記を統一する。漢字とひらがなで迷う語は、ひらがなで書く（出典: JTF §2.2.1 p.21, p.25）
- 専門用語は、言い換える・説明を付けて使う・普及させたい語は説明を添えてそのまま使う、の三つから選ぶ（出典: 公用文 本体 Ⅱ-2 (5)、解説 p.22）
- 外来語は、定着している語はそのまま使う・言い換える（アジェンダ→議題）・説明を付ける・使い方を工夫する、の四つから選ぶ（出典: 公用文 本体 Ⅱ-3 (5)）
- 説明は段階を踏んで書く（大まかな説明→詳しい説明→関連語との違い）（出典: 公用文 解説 Ⅱ-4 p.24）
- 略語は、元の用語を示してから使う（出典: 公用文 本体 Ⅰ-6ク (5)）

## プロジェクトで決めること

資料が選択を認めているか、資料どうしで扱いが違う項目。**ハーネスは既定を押し付けず、`voice.md` と用語集に記録させる。**

| 項目 | JTF | 公用文 |
|---|---|---|
| 敬体か常体か | 一般の読者向けは敬体 | 目的と読み手で選ぶ |
| 語末の長音 | 付けるのが原則。業界のゆれ（メモリ）を認める | 付けるのが原則 |
| 算用数字・英字の全角か半角か | 半角が原則 | 統一だけを求める（データは半角） |
| 読点 | 「、」 | 横書きで「，」も可 |
| 括弧の中で文が終わるときの句点 | 打たない | 打つ（引用・語句だけのときは打たない） |
| 及び／および、又は／または | 接続詞は仮名 | 漢字が原則。解説・広報では仮名も可 |
| 複合名詞の送り仮名（取扱い／取り扱い） | 組織で決める | 告示・通知は省く。解説・広報は学校の表記も可 |
| 一つ／1つ | 「3つのボタン」と算用数字 | 「一つ」が原則。広報で数えるときは算用数字 |
| 入れ子の括弧 | 『』 | 「」や（）をそのまま重ねる |

ほかに、カタカナ複合語の区切り、単位の書き方（英字かカタカナか、数値との間のスペース）、行頭記号・矢印・コロンの用法もプロジェクトが決める。

## 書くときのチェック項目

- [ ] 文書の中で敬体と常体が混ざっていない（引用と箇条書きは除く）
- [ ] 見出しの文末に句点がなく、見出しどうしの文体がそろっている
- [ ] 箇条書きのまとまりごとに、文体と文末の句点の有無がそろっている
- [ ] 形式名詞（こと・とき・ところ・もの・とおり・ため）と補助動詞が仮名になっている
- [ ] 同じ語に複数の表記がない（長音・送り仮名・カタカナ複合語の区切り）
- [ ] 一文の論点が一つで、50〜60字を超える文を見直した
- [ ] 三つ以上の並列を箇条書きにした
- [ ] 結論が先に来ている
- [ ] 「幾つか」「早めに」のような程度表現を、数値や期日に置き換えた
- [ ] 例示の語（`など`）の前に代表例を挙げた
- [ ] 専門用語・外来語・略語に、言い換えか説明か元の用語を付けた
- [ ] 二重否定・不要な受身・「〜することができる」を見直した

## 機械で検査できそうなこと

- 文末表現の混在（**実装済み**: `check-docs` の `voice.endings`）
- 語末の長音のゆれ（**実装済み**: 用語集の禁止表記）
- 「，」「．」と「、」「。」の混在、半角カタカナ、決めた方式と違う側の全角英数字
- 範囲を示す半角「~」、「ヶ所・ヶ月」
- 見出しの末尾の「。」
- 一文の文字数（上限はプロジェクトが決める）
- 定型の言い換え候補（「することができる」「を実施する」「事」「時」「出来る」「下さい」）。漢字が正しい用法もあるため、候補として示すだけにする
