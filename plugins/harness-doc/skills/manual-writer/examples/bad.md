# 悪い例: 開発環境のセットアップについて

<!-- check-docs: skip（この文書は「悪い例」で、わざと規則に違反している。ハーネス自身の検査対象から外す） -->

## 概要

このドキュメントでは my-app の開発環境のセットアップ方法などについて説明します。
基本的には以下の手順で進めれば問題ないはずですが、環境によっては適宜調整が必要になる場合があります。

## セットアップ

まず必要なパッケージをインストールし、環境変数を設定してから、サーバーを起動します。
```
npm install
```
インストールにはしばらく時間がかかります。終わったら設定ファイルを用意して、必要に応じて
DB の接続先などを書き換えてください。そのあと dev サーバを立ち上げればブラウザで確認できます。

うまくいかない時はポートが競合しているか、Node のバージョンが古いことが多いので、
いい感じに対処してください。詳細は [Wiki](../wiki/setup.md) を参照。

| タイトル「〜について」 | 読者がやりたいことになっていない | 目次から探せない | 「開発サーバーを起動する」 |
