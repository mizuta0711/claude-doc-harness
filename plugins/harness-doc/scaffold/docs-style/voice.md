# 文体と見た目（ボイス＆トーン）

このプロジェクトの文書を**どんな調子で書き、どう見せるか**を決める。
**誰が読むか・何を扱わないか**は、ここではなく文書群ごとのブリーフ（`.claude/rules/doc-brief-*.md`）にある。
一部の文書群だけ調子が違うときは、その違いをブリーフの「文体の差分」に書き、ここはプロジェクトの多数派のままにする。
`manual-writer` は書く前にこれを読み、`doc-reviewer` はこれに沿っているかを点検する。
`setup-project` が対話で作り、`change-tone` が変える。**手で直してもよい。**

## 文体

| 項目 | 設定 |
|---|---|
| 文末 | （例: 敬体（です・ます） / 常体（だ・である）） |
| 語りかけの温度 | （例: やわらかい・親しみ / ていねい・標準 / 簡潔・事務的） |
| 専門用語 | （例: 使わない・言い換える / 初出で説明して使う / 説明なしで使う） |
| 一文の長さの目安 | （例: 40字以内 / 60字以内 / 80字以内） |
| 読者への呼びかけ | （例: 呼びかけない / 「あなた」 / 「お客さま」） |
| 手順の書き方 | （例: 「〜してください」 / 「〜します」 / 「〜する」） |

## 見本の文

この調子で書く、という見本を2〜3文置く。設定表より見本の方が伝わる。

> （見本）

## 要素ごとの見本の文

地の文だけで合わせると、警告や FAQ が書く人ごとにばらつく。要素ごとに1文ずつ置く。

| 要素 | 見本 |
|---|---|
| 手順 | （例: **保存** を押してください。「保存しました」と表示されます。） |
| 警告 | （例: 電源を切る前に、必ず保存してください。保存しないと、入力した内容が消えます。） |
| うまくいかないとき | （例: 「接続できません」と表示されたら、Wi-Fi がオンになっているかを確かめてください。） |
| FAQ の問い | （例: 文字を大きくするには？） |

## 表記

資料どうしで扱いが違う項目は、ここで決める（`manual-writer` の知見のまとめより、こちらが優先）。

| 項目 | 設定 |
|---|---|
| 画面名・ボタン名の囲み方 | （例: 太字（**保存**） / かぎ括弧（「保存」））。決めると `manual-writer` の書き方の規則7 より優先する |
| 数字 | （例: 半角） |
| 長音 | （例: `サーバー` / `サーバ`。決めたら用語集にも入れる） |
| 括弧の中の句点 | （例: 付けない） |
| 操作の動詞 | （例: 押す / タップ / クリック。決めたら用語集にも入れる） |
| 画面のたどり方 | （例: 「設定」→「表示」の順に押す / 設定 > 表示） |
| コード・ファイル名・設定のキーの囲み方 | （例: インラインコード（`config.json`）/ HTML は `<code>`） |

## 警告の表し方

| 項目 | 設定 |
|---|---|
| 段階 | （例: 注意 / 警告 の2段階） |
| 表し方 | （例: 文頭に「注意:」。HTML は既存の注意書きの部品） |
| 置く位置 | （例: その操作の直前） |

## 変えてはいけない文言

法令・規約・免責・安全に関わる文。テイストを変えるときも、読者役の指摘があっても、**この文言は変えない**。

- （例: 「緊急通報（110・119）は、このアプリからはかけられません。」）

## 読者向けの改訂履歴

読者向けの改訂履歴を付ける文書群（ブリーフで「あり」）での書き方。

| 項目 | 設定 |
|---|---|
| 置く位置 | （例: 文書の末尾の「改訂履歴」の節 / サイトの改訂履歴のページにまとめる。まとめるときは、ブリーフの「読者向けの改訂履歴 / 置き場所」にそのページのパスを書く） |
| 書き方 | （例: 「いつ・どこを・どう変えたか」を1行で。読者に向けた言葉で） |
| 誤字・表記の修正 | （例: 載せない / まとめて1行） |
| 版の付け方 | （例: 付けない / 事実か構成が変わったら小さい番号を上げる） |

- （例: 絵文字、感嘆符、擬音語）

## 図と画面

画像・図を付けるのは、言葉では伝わらない節だけ（どの節に付けるかは、改訂設計書の目次案で節ごとに決める）。撮るたびに条件を決め直さないよう、ここに決める。

| 項目 | 設定 |
|---|---|
| 図の描き方 | （例: スクリーンショット / CSS のモック / CSS の図部品 / 文字の擬似図（枠線と記号で描いた図）） |
| 撮影の方法 | （例: スキル `harness-android:capture-screenshots` / スクリプト `tools/capture.ps1` / なし。**なしなら撮らない**） |
| 画面の条件 | （例: 端末・解像度・テーマ（明暗）・言語・文字の大きさ） |
| 画面に出すデータ | （例: 下の「例に使う名前」の値を登録した状態で撮る） |
| 隠すもの | （例: 実在のアカウント・個人情報・鍵・ユーザー名入りのパス。不透明の塗りつぶしで隠す） |
| 置き場と命名 | （例: 文書と同じフォルダーの `images/` に `<文書名>-<連番>.png`） |

## 例に使う名前

文書群で例に使う値を揃える（ばらばらだと、読者は別のシステムの話だと思う）。**人名・URL・電話番号・メールは、例のための値を選ぶ**（実在の値を例に使うと、読者が本物だと思って連絡する）。アプリ名・プロジェクト名は実在の名前でよい。
変えるときは、文書の例と画像を差し替える改訂（規模 M 以上）として頼む。

| 項目 | この文書群で使う値 |
|---|---|
| 利用者の名前 | （例: 山田 花子） |
| プロジェクト名・アプリ名 | （例: そのプロジェクト自身の名前） |
| ホスト名・URL | （例: `example.com`。RFC 2606 で例に使うために予約されている） |
| 電話番号 | （例: `090-0000-0000`。割り当てられていない形の例。予約された番号ではない） |
| メールアドレス | （例: `hanako@example.com`） |
