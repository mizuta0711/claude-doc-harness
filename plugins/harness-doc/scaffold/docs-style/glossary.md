# 用語集

このプロジェクトの文書で使う用語の表記を固定する。**同じものを2つの名前で呼ばない。**

- 「禁止表記」の語が本文にあると `check-docs` フックが止める（コードとして囲んだ部分は除く）
- 禁止表記は `、` で複数書ける。無い場合は `—`
- 推奨表記の先頭部分が禁止表記になる語（例: `サーバー` / `サーバ`）は、推奨表記として読める位置では検出しない
- 禁止表記を含む別の語（例: `ユーザ` を禁止したときの `ユーザビリティ`）は、その行の「例外」の列に書くと検出しない。`、` で複数書ける。無い場合は `—`。**長音の規則を入れるときは、長音の付かない別の語が止まらないかを確かめ、止まるならここに足す**（ハーネスに例外の既定値は無い）
- 用語を足すときは「意味」を1行で書く。意味を書けない語は、まだ用語にしない
- **長音を付けるか（`サーバ` / `サーバー`）のような表記の好みも、ここで決める。** 決めるのはこのプロジェクトで、ハーネスの既定は無い
- プロジェクトが既に用語表を持っている場合は、`.claude/doc-harness.config.json` の `glossaryFiles` にそのパスを書けば、それも読む
