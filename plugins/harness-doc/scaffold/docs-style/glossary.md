# 用語集

このプロジェクトの文書で使う用語の表記を固定する。**同じものを2つの名前で呼ばない。**

- 「禁止表記」の語が本文にあると `check-docs` フックが失敗する（インラインコードとコードブロックは除く）
- 禁止表記は `、` で複数書ける。無い場合は `—`
- 推奨表記の先頭部分が禁止表記になる語（例: サーバー / サーバ）は、推奨表記として読める位置では検出しない
- 用語を足すときは「意味」を1行で書く。意味を書けない語は、まだ用語にしない

| 推奨表記 | 禁止表記 | 意味 |
|---|---|---|
| Claude Code | ClaudeCode、claude code | Anthropic の CLI / IDE 拡張。このハーネスが動く環境 |
| サーバー | サーバ | 長音は省略しない（ユーザー、ブラウザー、エラーも同じ） |
| ユーザー | ユーザ | 長音は省略しない |
| 読者役レビュー | 読者レビュー、リーダーレビュー | `doc-reviewer` が予備知識のない読者になりきって文書だけで作業できるかを点検すること |
| 読者プロファイル | 読者像ファイル、ペルソナ | `profiles/` にある読者像・つまずく点・書き方の調整・レビュー観点をまとめたファイル |
| 曖昧語 | あいまい語 | `banned-words.txt` にある語。条件と値を書かずに済ませるための語 |
| 手順書 | ハウツー、操作手順書 | 読者が何かを「できるようになる」ための文書。`templates/howto.md` の型 |
| リファレンス | 参照資料 | 項目を「引く」ための文書。`templates/reference.md` の型 |
| 仕様書 | スペック | 振る舞いと制約を「決める」ための文書。`templates/spec.md` の型 |
