# 見た目の方向性（HTML の文書だけ）

**既存のサイトでは使わない。既存の CSS が正**で、ハーネスはそれを上書きしない。
新しく HTML のサイトやマニュアルを作るとき、`setup-project` が利用者に選んでもらう。
`change-tone` で見た目を変えるときは、既存 CSS の変数（色・文字の大きさ・余白）だけを変え、HTML の構造は変えない。

どの方向性でも守ること:

- 本文の文字と背景のコントラスト比は 4.5:1 以上
- 色だけで意味を伝えない（注意は色に加えて「注意」の文字やアイコン）
- 本文の1行は全角35〜45字程度に収める（`max-width` で制御）
- 画像には内容を説明する `alt` を付ける

## 1. シンプル

一般の利用者向けのサイト・マニュアル。

| 項目 | 値 |
|---|---|
| 本文の文字サイズ | 16px |
| 行の高さ | 1.8 |
| 本文の最大幅 | 720px |
| 配色 | 白地・濃いグレーの文字（#222）・アクセント1色 |
| 見出し | 太字。下線や背景色は使わない |
| 図 | スクリーンショットに番号付きの吹き出し |

## 2. やさしい・大きめ

シニア・初めての人向け。押す場所と順番が一目で分かることを最優先にする。

| 項目 | 値 |
|---|---|
| 本文の文字サイズ | 20px |
| 行の高さ | 1.9 |
| 本文の最大幅 | 680px |
| 配色 | 白地・黒に近い文字（#111）・ボタンの色をアプリの実物に合わせる |
| 見出し | 大きめ。手順は大きな番号の丸で示す |
| 図 | 画面を大きく見せ、押す場所を太い枠で囲む |
