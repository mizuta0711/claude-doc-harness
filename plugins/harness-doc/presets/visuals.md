# 見た目の方向性（HTML の文書だけ）

**既存のサイトでは使わない。既存の CSS が正**で、ハーネスはそれを上書きしない。
新しく HTML のサイトやマニュアルを作るとき、`setup-project` が利用者に選んでもらう。
`change-tone` で見た目を変えるときは、既存 CSS の変数（色・文字の大きさ・余白）だけを変え、HTML の構造は変えない。

どの方向性でも守ること（出典は `show.mjs reference accessibility`）:

- 本文の文字と背景のコントラスト比は 4.5:1 以上。大きな文字は 3:1 以上（WCAG 2.2 1.4.3）。UI 部品と図の要素は隣の色と 3:1 以上（1.4.11）
- 色だけで意味を伝えない。注意は色に加えて「注意」の文字やアイコンで示す（1.4.1）
- ブラウザで文字を 200% まで拡大できる。文字サイズを固定しない。`user-scalable=no` を使わない（1.4.4）
- 幅 320 CSS px で横スクロールが要らない（1.4.10）
- 本文の1行は全角40字以内を目安にする（1.4.8 は AAA で「CJK は 40 字以内」。国内の目標の AA では必須ではない）
- 画像には内容を説明する `alt` を付ける。飾りの画像は `alt=""`（1.1.1）
- `<html lang="ja">` を付ける（3.1.1）

**下の各方向性の数値（文字の大きさ・行の高さ・最大幅）は、ハーネスが決めた初期値で、出典は無い。**
本文の最小の文字の大きさと行間の倍率は、調べた範囲（NN/g・WCAG・デジタル庁）で確かめられなかった。
