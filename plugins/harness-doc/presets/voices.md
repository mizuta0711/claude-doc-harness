# 文体の見本集

`setup-project` と `plan-doc`（テイスト変更の試作）が、利用者に文体を選んでもらうときに見せる。
**設定表より見本の文で選んでもらう。** 同じ内容（電話をかける・設定を保存する）を各文体で書いてある。

## A. やさしい敬体

初めて使う人、機械が苦手な人、シニアとその家族向け。

| 項目 | 設定 |
|---|---|
| 文末 | 敬体（です・ます） |
| 語りかけの温度 | やわらかい・親しみ |
| 専門用語 | 使わない・言い換える |
| 一文の長さの目安 | 40字以内 |
| 読者への呼びかけ | 呼びかけない |
| 手順の書き方 | 「〜してください」 |

> 電話をかけるときは、緑色の「電話」ボタンを押してください。
> 相手の名前が大きく表示されたら、つながっています。

## B. 標準の敬体

一般の利用者向けのマニュアル・サイト。迷ったらこれ。

| 項目 | 設定 |
|---|---|
| 文末 | 敬体（です・ます） |
| 語りかけの温度 | ていねい・標準 |
| 専門用語 | 初出で説明して使う |
| 一文の長さの目安 | 60字以内 |
| 読者への呼びかけ | 呼びかけない |
| 手順の書き方 | 「〜します」 |

> 設定画面で［保存］をクリックします。
> 保存が終わると、画面上部に「保存しました」と表示されます。

## C. 簡潔な常体

開発者・技術者向けのリファレンス、仕様書、README。

| 項目 | 設定 |
|---|---|
| 文末 | 常体（だ・である） |
| 語りかけの温度 | 簡潔・事務的 |
| 専門用語 | 説明なしで使う（用語集にある語） |
| 一文の長さの目安 | 80字以内 |
| 読者への呼びかけ | 呼びかけない |
| 手順の書き方 | 「〜する」 |

> 設定は `config.json` に保存する。保存後の再起動は不要である。
> 接続先が応答しない場合、10秒でタイムアウトする。

## D. 運用手順（指示型の敬体）

障害時に焦って読む運用担当向けの手順書。

| 項目 | 設定 |
|---|---|
| 文末 | 敬体（です・ます） |
| 語りかけの温度 | 簡潔・事務的 |
| 専門用語 | 説明なしで使う（運用担当が知っている語） |
| 一文の長さの目安 | 40字以内 |
| 読者への呼びかけ | 呼びかけない |
| 手順の書き方 | 「〜します」。結論とコマンドを先に置く |

> サービスを再起動します。次のコマンドを実行します。
> `active (running)` と表示されれば復旧しています。

## 数値の出典

一文の長さの目安（40字・60字・80字）は、**ハーネスが決めた初期値**である。根拠として確かめられたのは次の2つ。

- 公用文作成の考え方の解説は「50〜60字を超えたら読みにくくなっていないか見直す」を目安にしている（「一概に決められない」と断ったうえで）
- 英語圏の基準（GOV.UK の25語、NN/g の15〜20語）は単語数で、日本語の文字数への換算は無い

詳しくは `show.mjs reference japanese` と `show.mjs reference web`。

## 選んでもらった後

- 選んだ見本の設定表を `docs-style/voice.md` の「文体」に写す。見本の文も写す
- 利用者が一部だけ変えたい場合（「B だけど専門用語は説明なしで」）は、その項目だけ書き換える
- 文末に応じて `.claude/doc-harness.config.json` の `voice.endings` を `keitai`（A・B・D）か `jotai`（C）にする。
  1つのプロジェクトで敬体と常体を混ぜる（利用者向けは敬体、仕様書は常体）場合は `null` にして、機械では検査しない
