# 改訂記録: {{文書群の名前}}
<!-- harness-doc: history 1 -->

この文書群の文書を直したときの**内部の記録**。読者には見せない（公開するサイトに含めない。読者役のレビューにも渡さない）。
**次に直すときは、対象の文書の節を先に読み、これまでの改訂意図と見送ったことを踏まえて方針を決める。**
新しい改訂を上に足す。過去の節は書き換えない。書き込みは harness-doc のスクリプト（`history.mjs add`）で行う。

「内部」は公開物の外という意味で、秘密ではない。このファイルはリポジトリにコミットされる。
